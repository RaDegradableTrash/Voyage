# 体积云

入口：`Assets/Settings/PC_Renderer.asset` → **Voyage Volumetric Clouds**。
Game 和 Scene 视图的基础相机均可显示云，叠加相机不重复合成。

## 调节

- `coverage`：横向云带的覆盖率，默认 0.52，0 时天空完全无云。
- `density` / `extinction`：云体浓度和每米消光，增大后云更厚实。
- `erosion`：云边破碎程度，默认 0.38，越低越柔和完整。
- `bottomHeight` / `topHeight`：世界空间云层高度，默认 900–1800 米。
- `noiseScale`：云团尺寸的倒数，降低后云团更大。
- `maxDistance`：最远步进距离，末端 20% 平滑淡出，默认 120 公里；细节随采样尺度减弱，远云接近地平线。
- `resolutionScale` / `primarySteps` / `lightSteps`：默认 0.6 / 64 / 4；性能需在目标硬件上实测。
- `reflectionSteps`：水面全方向云反射步进数，默认 32；反射贴图为 512×256 半浮点上半球全景。

## 实现

`CloudDensity.hlsl` 以扭曲的连续噪声定义横向云带、平缓云底、局部隆起与高层薄絮；不再使用球体格点。
不同高度的云轮廓会发生错移，避免形成垂直挤出的柱状侧壁。单条视线对云层交段的前 10 公里进行细节步进，云层交点本身可远至 120 公里。
云层与水面的全景倒影共用这份密度函数、光线积分、昼夜照明和累计风偏移。
水面的旧 `reflectedCloud*` 字段为序列化兼容保留，不再控制新云的形状。
云反射从相机关于海平面的镜像位置步进生成，覆盖 360° 方位和地平线至天顶。贴图坐标仅由世界空间反射方向决定，与相机朝向、视野角度和屏幕边缘无关。反射质量低于主云层，但不再切换屏幕内/屏幕外算法。
近处由以米为单位的长波和短风纹扭曲倒影；每个波段按像素覆盖的世界尺寸过滤，避免远处混叠。高光仅保留较弱的太阳光泽。水材质的 `Reflection Wave Distortion` 可调节反射破碎程度，0 为平静法线对照。
此全景仅包含天空和云，不包含地形、车辆等场景物体；波纹使用镜像位置全景做近似反射，不是逐像素追踪完整场景。

云光照通过 `CloudLightingBridge` 接入太阳、月亮和昼夜环境色；沿光源方向的采样长度独立于视线。
风偏移按速度积分，避免把瞬时阵风乘以游戏运行时间造成云层跳跃。
日落光照包含暖色边缘散射与偏紫的阴影底色。太阳的地平线可见性使用归一化渐变，避免落日前提前熄灭。

远海使用固定的世界海平面（默认 Y=-600）和 1000 公里稀疏外环；仅压缩远处顶点的裁剪深度，不抬起远海几何、不增大地形相机的远裁剪距离。海面与 120 公里远云在同一地平线附近汇合。

URP RenderGraph 在不透明物体和天空之后生成带 alpha 的半浮点云纹理，在合成前发布纹理。
合成采用深度加权的四点升采样；细小前景没有可用低分辨率样本时，对该像素补做步进。
主云纹理与反射全景均为预乘颜色。反射贴图在透明水面绘制前发布，独立于主相机画面。

## 回归检查

1. 默认设置能看到横向云带和细碎边缘，覆盖率或密度为 0 时保持原始画面。
2. 从云层下方、内部、上方观察，并检查接近水平的视线和正交相机。
3. 对着车辆、细杆和山脊转动相机，检查前景边缘没有云色外溢。
4. 切换昼夜、改变风速，检查光照同步和云移动连续性。
5. 关闭 renderer feature，水面不再引用上一帧的云；恢复后重新显示。
6. 用 GPU Profiler 检查 `Voyage Volumetric Clouds` 与 `Voyage Cloud Composite` 的成本。

# 可编辑的草

Unity 菜单：**Tools → Voyage → Grass Painter**。请在非运行状态编辑。

1. 点击 **Load vehicle spawn area** 加载车辆出生点附近，或把 Scene 视图移动到目标位置，点击 **Load / create patches near Scene view**。
2. 勾选 **Enable grass brush**。
3. 鼠标左键拖动刷草；按住 **Shift** 拖动擦除。**Ctrl+Z / Ctrl+Y** 撤销或重做。Alt 仍可操作场景视角。
4. Radius 控制笔刷半径，Strength 控制强度，Hardness 控制软边，Target density 控制目标密度。
5. 松开鼠标时会保存；也可以点击 **Save painted patches**。关闭窗口只移除预览，不删除已画的草。

首次打开一个区块，会按可种草的网格表面创建 78% 密度的初始分布。重新打开已有区块不会覆盖绘画。已准备出生点附近 3×3 共 9 块；地图其余区域需按需加载、创建和绘制，未绘制区域在游戏中按区块分帧生成草，保存的笔刷数据优先且不会被覆盖。

绘画保存在 `Assets/GrassFlowPaint/Resources/GrassFlow/Tiles`。选择相应 Grass 资源可调整草高、每行候选草数量和显示距离。每行数量的平方就是该区块的候选数：默认和上限为 256² = 65,536 个草簇位置。默认 Golden Meadow 为细密金色草甸：近景 36 根细叶、中景 12 根、远景 4 根，16 米和 38 米切换 LOD，最远 90 米，并按距离减密。草根逐根贴合地形；世界坐标噪声控制轻微疏密变化，连续风场形成麦浪。提高数量或显示距离会增加 GPU 开销。

`Assets/TerrainSystem/Source/TerrainChunkSettings.asset` 的 **Use Painted Grass** 已开启，用于停用旧的运行时草生成。旧代码与原有分布资源仍保留，便于回退。昼夜颜色和轮胎附近的压草效果沿用项目参数。

验证覆盖笔刷增删、跨块接缝、Undo、网格覆盖范围、实际 URP 绘制、昼夜颜色和清空密度后的 GPU 实例移除。受控渲染对比可通过 Unity batchmode 执行 `GrassFlowBenchmark.Run`（不要加 `-quit`，工具会在采样结束后退出）。该对比包含同步读回，不能当作完整游戏帧率。


样式名称约定：**“芦荟” = Aloe**，专指此前宽叶、放射状草簇版本（9 / 5 / 3 片叶）。此版本已保留，但不再默认启用。选择 Grass 资源，将 Style 改为 Aloe 即可恢复；Golden Meadow 是当前细密金色草甸。这个称呼用于后续交流与版本识别。

Golden Meadow Palette 调整新草甸根、叶和叶尖色；Aloe palette 下原有颜色用于芦荟。Wind Strength 控制风力。样式切换不覆盖已画密度。

车辆轮胎由现有 GrassInteractionSystem 注册接触并生成压草场，新草甸逐根响应，包含静止压力和随时间恢复；其他移动物体可添加 GrassInteractionEmitter。没有逐根草的物理 Collider。



性能修复：进入 Play Mode 自动清除笔刷预览，避免重复渲染。未绘制区块仅在接近时生成，多个区块共享每帧约 1.5 ms 的栅格化预算。草与地面共享 VoyageMeadowLighting 光照、阴影和底色，远景覆盖感由底色衔接。


灰麦色修订：降低饱和度，增加短草与长草的高度层次。草甸颜色以线性 Vector 数据传入，避免 Color 属性的色彩空间转换与地面常量不一致。草根使用地面法线、共用环境光和阴影，不额外叠加根部染色。远景描边使用倒数深度的不连续检测，避免连续坡面产生横带；地形深度与颜色通道共用 LOD/范围裁剪。芦荟仍保留原配色与模型。

远景轮廓修订：44 / 15 / 5 片叶的小幅加密，保持原笔刷遮罩。近远景共用雾后暗色描边；低于 1.5 米的深度跳变不描边，以抑制草叶噪点。Persistent distant terrain 使用原地形 LOD3，每 8×8 个 tile 合批，不带草、碰撞或阴影投射，最远可见 12 公里。修改地形后使用 Voyage > Terrain > Rebuild distant horizon 重建远景资源。
描边深度单独绘制地形和物体，排除 VoyageGrass（第 8 层），避免密草形成暗带。自定义相机的 Culling Mask 需要包含 VoyageGrass 才能看见草。
